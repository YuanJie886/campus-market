## 3. 真实浏览器 E2E（8.1，阶段 0 按新方向改写）

- 工具：Playwright（`@playwright/test`）；本机用已安装的 Google Chrome（`channel=chrome`，没有下载浏览器）；CI 用 Playwright 自带的 Chromium。
- 测试栈：前端 REST 构建 + 后端 jar + 一次性 PostgreSQL 16（`e2e/stack/*`）；MockMvc、jsdom、直接调用接口都**不算**在这里。
- 隔离：每个参与方一个独立的 browser context；账号每次随机；除本机测试栈外的网络请求全部拦截。
- 失败产物：截图 + 脱敏 trace（删除网络记录与响应体、替换本次的密码 / 令牌 / Cookie / 邀请码与任何 JWT）；
  Playwright 自动生成的文本附件由 `e2e/redact-reporter.ts` 再脱敏。
- 结果（2026-10-19）：**15/15 通过，连续两次**（`npx playwright test` 与 `npm run e2e`）；结束后没有残留容器或卷。
