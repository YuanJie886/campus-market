## 改版落地（P0 + P1 已实施）

改动文件：`src/app.scss`、`src/components.tsx`、`src/pages/{market,detail,publish,notifications,profile,listings,login}/index.tsx`。

- `app.scss` 重写为 token 层：颜色 CSS 变量定义在 `page`，字号 7 档（最小 11px），字重只用 400/500/600/700，圆角 8/12/14/24/999，间距 4 倍数。
- 图标改为 data-URI SVG（`.i-search` 等），已通过微信官方 wcsc 编译校验，避免文本字符跨机型差异。
- 集市：删除 intro banner；搜索框 sticky；分类 chips 带 emoji；排序改常驻 tab（最新/价格⇅/浏览）；筛选改底部面板式 chips；卡片标题 2 行、价格 tabular-nums、元信息 11px。
- 详情：图集通栏 340px + 计数；价格 28/700 + 语义色 pill；商品情况摘要（正常/异常分色）；CTA 固定「我想要」，状态改用按钮上方 hint 表达。
- 发布：拆 3 步（照片 → 名称/描述/分类/成色/价格/地点 → 情况/联系方式），分类与成色改 chips，价格带 ¥ 前缀，清单失败可重试且不阻塞提交。
- 通知：标题事实化 + 待处理数；segment 带数量；状态三色（warn/ok/mute）；卡片带头像与商品缩略图。
- 踩坑记录：
  - 新增文本类必须补进 `display:block` 白名单，否则 Taro `<Text>`（渲染为 span）会和相邻文字挤在一行。
  - `button::after` 在 weapp 有默认样式，做热区扩展时要显式 `width/height:auto; transform:none; border:0`。
  - `.product-grid` 的左右留白不要写死，否则在带 padding 的页面（收藏列表）会叠加成 32px。
- 未做：custom-tab-bar 凸起 FAB、深色模式、草稿保存。
